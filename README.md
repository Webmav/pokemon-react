## About

Pokemon Api is a simple page where you can search for a Pokémon and see its sprite image. Once you find the one you like, you can save the image straight to your device.

## Features

- Search for Pokémon images by name
- Fetch sprites live from the Pokémon API
- Download a sprite to your device

## How It Works

1. Type a Pokémon name into the search box.
2. The app requests that Pokémon's data from the Pokémon API.
3. The sprite image is displayed on the page.
4. Click the download button to save the image to your device.
